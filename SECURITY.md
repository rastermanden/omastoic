# Security

Report a vulnerability privately as a GitHub Security Advisory for
`rastermanden/omastoic`:

<https://github.com/rastermanden/omastoic/security/advisories/new>

Use that form. Do not put vulnerability details in a public issue, discussion,
or pull request. This project has no security email address. No response time
is promised.

Private vulnerability reporting has to be enabled in the repository security
settings before that form accepts a report.
